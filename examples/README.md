# Example Configurations

Example GatewayX configuration files for various deployment scenarios.

- `docker-compose-gatewayx.yaml` -- Configuration for Docker Compose deployment
- `tls-config.yaml` -- TLS/HTTPS configuration example
- `production.yaml` -- Production-grade route with auth, cache, rate limit, compression, health checks
- `oauth-github.yaml` -- OAuth 2.0 with GitHub login flow
- `websocket.yaml` -- WebSocket and real-time services
- `multi-tenant.yaml` -- Multi-tenant API with per-key rate limiting
